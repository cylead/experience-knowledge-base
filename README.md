# Experience Knowledge Base

A local-first Obsidian vault for turning sources and life experiences into connected knowledge and deliberate practice.

## The Role of the LLM

The LLM does not replace the user's thinking or act as the source of truth. Its role is to:

1. Extract concepts from the information the user provides.
2. Compare those concepts with previously recorded sources, insights, concepts, and practices.
3. Suggest useful matches, connections, or updates across the user's knowledge history.
4. Present the proposed changes for the user to review before anything is saved.

Original input is preserved, and LLM-generated suggestions are clearly labeled.

## Using the Vault

1. Open this folder as a vault in Obsidian.
2. Give the LLM agent a reflection in your own words and identify its source when there is one.
3. Review and approve the concepts and connections it proposes.
4. Browse the resulting knowledge network from `Home.md`.
